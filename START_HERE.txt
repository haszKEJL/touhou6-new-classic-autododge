Scarlet Assist 1.4.1
Author: haszKEJL

1. Extract the full ZIP.
2. Start Touhou 6 New Classic (th06nc.exe).
3. Run run.bat, then return to the game.
4. Insert opens the menu. Select ENG, PL or RU in the language selector.

F5 autoplay / F6 autobomb / F7 collection / F8 dodge / F9 disable all.
All features start OFF. Each supports custom keys and Toggle/Hold mode.
For dodge on Shift: select Hold, assign Shift, enable Armed, close the panel.
The panel pauses automation, NOT the game. Pause a stage before editing settings.
Restart the game after replacing the DLL.

Only New Classic 1.03 x64 with this executable SHA-256 is supported:
07850c8c6e469c0e82c13423e6d0d096a88d693455bdacacbb44c0aa3bcce473
Use default game controls and the same privilege level for game and launcher.
Extra-stage strategies are experimental; hits and failed runs are possible.

Dependency licenses are included in licenses/.
